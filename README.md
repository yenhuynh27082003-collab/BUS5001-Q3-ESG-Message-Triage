# BUS5001 Q3 – ESG Message Triage

This repository contains the Colab notebook used for Q3 of BUS5001 Assessment 3.

The notebook demonstrates:

- The original and revised LLM prompt
- Three ESG operational test messages
- Structured JSON classification outputs
- Hugging Face zero-shot comparison
- Classification consistency and confidence results
- Risk considerations and the proposed Azure deployment architecture

The notebook file is:

`Q3_ESG_Message_Triage_LLM.ipynb`

The experiment classified three messages concerning water, waste and accessibility issues. The LLM and Hugging Face classifier produced the same category for all three messages, resulting in 100% category consistency in this small test sample.

This repository provides supporting evidence for the Q3 written report.
